# USB_AUDIT — Hybrid WSL Network Audit Toolkit

> **Легальный инструмент аудита и инвентаризации локальных сетей.**  
> Предназначен только для тестирования систем, которыми вы владеете или имеете письменное разрешение на тестирование.

## Описание

`USB_AUDIT` — это переносимый гибридный аудит-набор, работающий с USB-накопителя на Windows 11. Он сочетает нативный сетевой движок Windows (Nmap) с аналитическим ядром на базе WSL/Kali Linux для сбора базовой информации об активных хостах локальной сети.

Ключевая особенность — архитектура **Zero-Mount Pipeline**: bash-скрипт не запускается напрямую с FAT32/exFAT флешки, а передаётся в WSL через `stdin`, что позволяет обходить проблемы с POSIX-правами на съёмных носителях.

## Состав репозитория

| Файл | Назначение |
|------|------------|
| `START_WSL.bat` | Windows-загрузчик. Запрашивает права администратора, определяет подсеть, запускает Nmap и передаёт данные в WSL. |
| `linux_audit.sh` | Linux-анализатор. Принимает Nmap-лог через stdin, выполняет SMB/HTTP/RDP валидацию и пассивный сниффер. |
| `nmap_setup.exe` | Установщик Nmap для Windows (если отсутствует). |
| `README.txt` | Исходное архитектурное описание v7.5. |
| `LINUX_AUDIT_REPORTS/` | Папка для сохранения отчётов. |

## Архитектура

```
[Windows 11 Host]
        │
        ▼
[PowerShell Network Discovery] ──► [Native Nmap Engine]
                                         │
                                         │ (stdout → stdin)
                                         ▼
                              [WSL 1 / Kali Linux]
                                         │
                                         ▼
                              [Bash Analyzer + Python Sniffer]
                                         │
                                         ▼
                              [Report on USB / Desktop]
```

## Требования

- Windows 10/11 с установленной подсистемой WSL (рекомендуется Kali Linux).
- Установленный Nmap в стандартном пути: `C:\Program Files (x86)\Nmap\nmap.exe`.
- Права администратора (необходимы для Nmap и работы с сырыми сокетами).
- `smbclient` и `curl` внутри WSL (для активной валидации SMB/HTTP).

## Использование

1. Скопируйте содержимое папки `USB_AUDIT` на USB-накопитель.
2. Убедитесь, что WSL с Kali Linux установлена:  
   ```powershell
   wsl --list --verbose
   ```
3. Запустите от имени администратора:  
   ```
   START_WSL.bat
   ```
4. Дождитесь завершения сканирования. Отчёт сохранится в `LINUX_AUDIT_REPORTS\Audit_Output_<timestamp>.txt`.

## Параметры сканирования

Скрипт использует следующие техники снижения шума:
- `-f` — фрагментация пакетов
- `--randomize-hosts` — случайный порядок опроса хостов
- `--spoof-mac 0` — случайный MAC-адрес источника
- `--scan-delay 300ms` — задержка между пакетами
- `-T3` — умеренная интенсивность
- Порты: `21,22,23,80,443,445,3389,8080`

## Важные замечания по безопасности

- **Используйте только на сетях, которыми вы управляете или имеете разрешение тестировать.**
- `--spoof-mac` и фрагментация пакетов могут вызывать ложные срабатывания в IDS/IPS.
- `smbclient -N` выполняет анонимный запрос; убедитесь, что это соответствует политике тестирования.
- Python-обработчик использует сырые сокеты; для его работы в WSL могут потребоваться права root.

## Кастомизация

Перед использованием рекомендуется изменить в коде:
- Диапазоны сканируемых подсетей в `START_WSL.bat` (строка 49).
- Список портов в строке 74 `START_WSL.bat`.
- User-Agent и внутренние ссылки в случае доработки анализатора.
