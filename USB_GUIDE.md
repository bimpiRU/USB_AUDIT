# USB-гайд: подготовка ПК и запуск аудита

> Этот гайд находится на флешке и дублируется в репозитории:  
> https://github.com/bimpiRU/USB_AUDIT

## 1. Подготовка ПК

### 1.1. Установка WSL + Kali Linux

Откройте PowerShell от имени администратора и выполните:

```powershell
wsl --install -d kali-linux
```

После установки создайте пользователя `kali` и пароль. Перезагрузите ПК.

Проверьте, что WSL работает:

```powershell
wsl --list --verbose
```

### 1.2. Установка Nmap

Если Nmap ещё не установлен, запустите с флешки:

```
E:\USB_AUDIT\nmap_setup.exe
```

Убедитесь, что `nmap.exe` появился по пути:

```
C:\Program Files (x86)\Nmap\nmap.exe
```

### 1.3. Подготовка Kali

Внутри Kali установите `smbclient` и `curl` (обычно уже есть):

```bash
sudo apt update
sudo apt install -y smbclient curl netcat-traditional
```

## 2. Подготовка флешки

Структура флешки должна быть такой:

```
E:\
├── USB_AUDIT\
│   ├── START_WSL.bat
│   ├── linux_audit.sh
│   ├── nmap_setup.exe
│   ├── README.txt
│   └── LINUX_AUDIT_REPORTS\
├── PyongyangPentestINC\
│   └── PyongyangPentestINC.sh
└── USB_GUIDE.md
```

## 3. Запуск USB_AUDIT

1. Вставьте флешку в ПК.
2. Убедитесь, что ПК подключён к целевой сети (Wi-Fi или Ethernet).
3. Откройте проводник, зайдите в `E:\USB_AUDIT`.
4. Правый клик по `START_WSL.bat` → **Запуск от имени администратора**.
5. Подтвердите запрос UAC.
6. Дождитесь окончания сканирования и нажмите любую клавишу.

Отчёт сохранится в:

```
E:\USB_AUDIT\LINUX_AUDIT_REPORTS\Audit_Output_YYYYMMDD_HHMMSS.txt
```

## 4. Запуск PyongyangPentestINC

> Используйте только в изолированной тестовой сети и только на оборудовании, которое вам принадлежит.

1. Откройте WSL/Kali.
2. Перейдите на флешку:

```bash
cd /mnt/e/PyongyangPentestINC
```

3. Запустите:

```bash
sudo ./PyongyangPentestINC.sh
```

Или с параметрами:

```bash
sudo /tmp/pyongyang_framework.sh -t 192.168.1.1 -c 500 -p 8080 -d 0.01
```

Лог honeypot по умолчанию сохраняется на рабочий стол Windows:

```
C:\Users\admin\Desktop\honeypot_capture.txt
```

## 5. Завершение работы

1. Остановите `PyongyangPentestINC` комбинацией `Ctrl + C`.
2. Закройте все окна WSL и CMD.
3. Проверьте, что отчёты сохранены на флешке.
4. Безопасно извлеките флешку.

## 6. Частые проблемы

### Nmap не найден

Убедитесь, что путь к `nmap.exe` совпадает с:

```
C:\Program Files (x86)\Nmap\nmap.exe
```

Если Nmap установлен в другую папку, отредактируйте строку 74 в `START_WSL.bat`.

### WSL не запускается

Проверьте, включена ли виртуализация в BIOS (Hyper-V / Virtual Machine Platform).

### Пустой отчёт

- Убедитесь, что ПК подключён к сети.
- Проверьте, что в подсети есть активные хосты.
- В `START_WSL.bat` строка 49 фильтрует только `192.168.x.x` и `172.16-31.x.x`. Если ваша сеть `10.x.x.x`, добавьте её в фильтр.

### Права доступа

`START_WSL.bat` должен запускаться от имени администратора. Без этого Nmap не сможет использовать `--spoof-mac` и фрагментацию.
