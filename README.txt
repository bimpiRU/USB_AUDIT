1. ТЕКУЩАЯ АРХИТЕКТУРА И ЛОГИКА ВЗАИМОДЕЙСТВИЯ (Hybrid-Stream v7.5)
----------------------------------------------------------------------
Классическая схема запуска Bash-скриптов из-под WSL 1/2 напрямую через монтирование дисков (/mnt/d/) на Windows 11 оказалась полностью нежизнеспособной по следующим причинам:
- Изоляция сетевых интерфейсов виртуальной среды (интерфейсы типа 'dev') приводила к сбросу низкоуровневых Syn-пакетов Nmap на уровне ядра Windows (Drop).
- Файловые системы съемных носителей (FAT32/exFAT) жестко блокировали выполнение скриптов из-за отсутствия поддержки прав доступа POSIX (ошибка 'Operation not permitted' при chmod +x).
- Попытки привязки сырых сокетов внутри Linux вызывали деградацию дескрипторов (error: 92 Protocol not available).

Решение: Мы реализовали "Протокол нулевого монтирования" (Zero-Mount Pipeline). 

[Архитектурная схема]:
[Windows 11 Host API] ---> (PowerShell Network Discovery) ---> [Native Nmap Engine]
                                                                        |
                                                   (Потоковая передача через STDIN)
                                                                        v
[WSL 1 / Kali Linux Memory] <--- (tr -d '\r') <--- [RAM /tmp/audit.sh Interpreter]
          |
          +---> (Парсинг сигнатур + Маппинг модулей Metasploit)
          |
          v
[Финальный UTF-8 лог на USB] <--- (CMD Stream Redirection)

2. ОБХОД ЗАЩИТНЫХ МЕХАНИЗМОВ И МАСКИРОВКА (Stealth & Evasion)
----------------------------------------------------------------------
Для предотвращения детекции со стороны локальных систем обнаружения вторжений (IDS/IPS) и брандмауэра Windows 11, в нативный сетевой движок Windows были внедрены четыре легитимные техники снижения шума:

1. Фрагментация пакетов (-f): Исходящий трафик Connect-сканирования дробится на минимальные фрагменты, что мешает сигнатурным анализаторам сетевых экранов собрать пакет в единый паттерн сканирования.
2. Десинхронизация хостов (--randomize-hosts): Опрос IP-адресов целевой подсети происходит в хаотичном (рандомном) порядке, что разрушает логическую цепочку последовательного сканирования.
3. Подмена MAC-адреса источника (--spoof-mac 0): При каждом цикле инициализации скрипт генерирует случайный аппаратный адрес сетевой карты, маскируя хост под случайного вендора оборудования.
4. Контроль интенсивности (--scan-delay 300ms): Между отправкой пакетов выдерживается искусственная пауза, нивелирующая резкие всплески сетевой активности (DoS-эффект).

- Для SMB 445: auxiliary/scanner/smb/smb_version и smb_enumshares (проверка гостевого входа).

Пассивный L3-анализатор транзакций сокетов на базе встроенного Python выполняет безопасный перехват дескрипторов сессий без использования внешней утилиты Tshark, что обеспечивает полную автономность при отсутствии интернет-репозиториев.

----------------------------------------------------------------------
Мы переходим от стадии пассивного сбора к стадии повышения практической ценности инструмента. Нам необходимо расширить код следующими автономными модулями (без использования внешних зависимостей и интернета):
